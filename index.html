                Quiz rules

                The quiz has 500 questions: 150 easy, 250 normal, 50 hard, and 50 very hard. Questions do not repeat within a run. Start with 3 lives. A wrong answer or timeout costs 1 life. A correct very hard answer restores 1 life, up to a maximum of 5. Easy and normal questions allow 5 seconds; hard and very hard questions allow 10. Press keys 1–4 to answer.

                Pity bar

                Easy answers add 10 points to the pity bar, and normal answers add 5. Each 50-point increase triggers a hard question and removes 50 points. Reaching 250 triggers a very hard question and removes 100 points. A hard question never follows a very hard question directly. The bar can drop below zero.

                Easy · Normal · Hard · Very hard

                Leaderboards

                The quiz leaderboard shows the top 10 runs, ranked by questions answered, correct answers, then fastest time. Qualifying players can submit a name of 3–13 characters. Offensive names are not allowed. Select the info icon to view a difficulty breakdown. Snake on the 404 page has a separate leaderboard ranked by apples eaten, then fastest time. Swipe or use the arrow keys or WASD to move. Collect apples and avoid sheet music.
